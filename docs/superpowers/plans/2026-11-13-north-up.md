# North Up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every real world is drawn with north straight up by default, each city able to turn back to its street grid with one line.

**Architecture:** The city's measured street-grid bearing (`gridDeg`) is separated from the bearing the view is turned to (`viewDeg(city)`: 45° for `view: "north"`, the default, or `gridDeg` for `view: "grid"`). The scene projects with the view's bearing; statues, written in the grid's frame, are turned into the view's frame. The manifest's `geo.betaDeg` is the view's bearing, so the viewer is unchanged but for its About notes. Every real city is then rendered again, with its cards, loops and hero slides.

**Tech Stack:** TypeScript ESM, vitest (pipeline), Next.js static export (viewer), HyperFrames + puppeteer (videos).

**Spec:** `docs/superpowers/specs/2026-11-13-north-up-design.md`

## Global Constraints

- North up is a view bearing of exactly 45° (`NORTH_UP_DEG = 45`); `manifest.northDeg` is then 0.
- `view` is `"north" | "grid"`, optional, default `"north"`.
- Generated cities (`generatedCity`) are always `view: "grid"`: Westeros (grid 45) stays north up, Winterfell and King's Landing (grid 0) do not move.
- The data contract (`manifest.json`, `geo.betaDeg`) does not change shape.
- No hard-coded interface strings: About notes in en-US, pt-BR, es-ES.
- Public repository: no domains, hosts or ids in tracked files.
- In this worktree session: one git command per Bash call, no heredocs (memory: worktree-session-shell-rules).

## Review Focus

- A statue box (the Hollywood Sign's letters, the Pioneer Monument's plinth, the Margaret Hunt Hill arch) must keep its compass orientation and position: its corners map to the same lon/lat whichever way the view is turned (Task 1 test `statueRing keeps the ground`).
- A generated world must not move: Winterfell's projection bearing stays 0, Westeros' 45 (Task 1 test in `generated.test.ts`).
- A city that sets `view: "grid"` must render exactly as before (Task 1 test `viewDeg` and the byte-identical preview check in Task 2).
- Screen-pixel framings (`HEROES` `dx`, `dy`; Dallas `dx: 250, dy: -30`) were tuned for the old turn: each plate is looked at before rendering (Task 5).
- The `index` step's sights pictures and outlines are map px: they must be regenerated with the tiles, never left from the old render (Task 3 checks `manifest.indexes` changed).

**Interfaces:**
- Produces:
  - `turnGrid(p: number, q: number, deg: number): [number, number]` in `projection.ts`: grid metres on a grid of bearing B → the same ground point's metres on a grid of bearing B + deg. With δ = deg in radians: `q' = q·cos δ − p·sin δ`, `p' = q·sin δ + p·cos δ`.
  - `NORTH_UP_DEG = 45` and `viewDeg(city: Pick<City, "gridDeg" | "view">): number` in `cities/view.ts`.
  - `City.gridDeg: number`, `City.view?: "north" | "grid"` in `types.ts`.
  - `statueRing(piece: StatuePiece, p: number, q: number, turnDeg: number): number[]` in `scene/statues.ts`: the piece's footprint ring in the view's grid metres, `p, q` being the statue's spot in the view's grid. Centre = spot + `turnGrid(piece.dp, piece.dq, turnDeg)`; a disc is `disc(centre, r, 8)` (from `medieval.ts`); a box is its four corners (±hp, ±hq) each turned by `turnGrid(…, turnDeg)` about the centre, in the same winding as today.
  - `GeneratedCity.gridDeg?: number` (renamed from `betaDeg`).

it("turnGrid moves a point between grids of two bearings without moving it on the ground", () => {
  const g = makeProjection(makeGeo(-73.98566, 40.74844, 28.9, 2));
  const v = makeProjection(makeGeo(-73.98566, 40.74844, 45, 2));
  for (const [p, q] of [[100, 0], [0, -250], [-37.5, 412]]) {
    const [pv, qv] = turnGrid(p, q, 45 - 28.9);
    const a = g.toLonLat(...g.gridToMap(p, q));
    const b = v.toLonLat(...v.gridToMap(pv, qv));
    expect(b[0]).toBeCloseTo(a[0], 9);
    expect(b[1]).toBeCloseTo(a[1], 9);
  }
});
it("turnGrid on a compass grid by 45° sends a metre north to (√½, −√½)", () => {

});

it("statueRing keeps the ground: a box's corners land on the same lon/lat whatever the view", () => {
  const grid = 0.2, view = 45;
  const g = makeProjection(makeGeo(-96.8, 32.78, grid, 2));
  const v = makeProjection(makeGeo(-96.8, 32.78, view, 2));
  const piece = { dp: 30, dq: -12, from: 0, to: 5, hp: 1.5, hq: 6, ramp: "white" } as const;
  const [p, q] = g.toGrid(-96.79, 32.781);
  const [pv, qv] = v.toGrid(-96.79, 32.781);
  const before = statueRing(piece, p, q, 0);
  const after = statueRing(piece, pv, qv, view - grid);
  for (let i = 0; i < before.length; i += 2) {
    const a = g.toLonLat(...g.gridToMap(before[i], before[i + 1]));
    const b = v.toLonLat(...v.gridToMap(after[i], after[i + 1]));
    expect(b[0]).toBeCloseTo(a[0], 9);
    expect(b[1]).toBeCloseTo(a[1], 9);
  }
});
it("statueRing with no turn is today's box", () => {

});
